# Original motifs only

The theme draws on Steins;Gate through generic ideas: nixie tubes, world lines, CRT terminals and
lab notes. Nothing copyrighted from the series is used: no characters, art, music, logos or quotes,
and the meter is our own design rather than a copy of the prop. Readings must not be numbers from
the series. This is a professional site on public GitHub, so the risk isn't worth a closer homage.
